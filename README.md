# Android 101

Homework projects from the Pirple course "Learn to build Android apps in Kotlin, from start to finish".

## About The Project

The course is 3 classes in 1: an introduction to Android Studio, the fundamentals of the Kotlin language, and a 5-day hands-on Android-app bootcamp. The repository contains the homework projects:

- Homework #1 - Android Studio/HelloWorld
- Homework #2 - Variables
- Homework #3 - Collections
- Homework #4 - Control Flow
- Homework #5 - Functions
- Homework #6 - Classes and Objects/Vehicle

### Built With

- Kotlin
- Android Studio
